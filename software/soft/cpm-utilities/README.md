# Narzędzia systemowe CP/M

## Opis

Standardowe i rozszerzone narzędzia systemu operacyjnego CP/M 2.2. Niezbędne do codziennej pracy z systemem.

## Pliki

### Podstawowe narzędzia CP/M
- **PIP.COM** (7 KB) — Peripheral Interchange Program — kopiowanie plików
- **ED.COM** (9 KB) — standardowy edytor tekstu CP/M
- **SUBMIT.COM** (2 KB) — przetwarzanie wsadowe (batch)
- **XSUB.COM** (2 KB) — rozszerzony SUBMIT z parametrami
- **STAT.COM** (5 KB) — status systemu (wolna przestrzeń, itp.)

### Debuggery
- **SID.COM** (8 KB) — Symbolic Instruction Debugger
- **ZSID.COM** (10 KB) — Z80 Symbolic Instruction Debugger (rozszerzony)

### Zarządzanie dyskami
- **FORMAT.COM** (2 KB) — formatowanie dyskietek
- **DUU.COM** (7 KB) — narzędzie dyskowe (Disk Utility)
- **FILCOM.COM** (7 KB) — porównywanie plików
- **MF.COM** (2 KB), **MFU.COM** (2 KB) — kopiowanie/przenoszenie plików
- **UNERASE.COM** (1 KB) — odzyskiwanie skasowanych plików

### Polskie narzędzia
- **KATALOG.COM** (4 KB) — wyświetlanie katalogu (polski)
- **WYDRUK.COM** (9 KB) — drukowanie plików (polski)

### Inne
- **TRPLIK.COM** (3 KB) — transfer plików
- **TESTRAM.COM** (256 B) — test pamięci RAM

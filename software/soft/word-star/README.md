# WordStar

## Opis

WordStar — najpopularniejszy edytor tekstu dla systemu CP/M. Używany przez użytkownika do pisania dokumentów urzędowych, notatek akademickich i dokumentacji technicznej.

## Pliki

- **WS.COM** (18 KB) — główny program
- **WSMSGS.OVR** (30 KB) — nakładka z komunikatami
- **WSOVLY1.OVR** (33 KB) — nakładka pomocnicza
- **WSPRINT.COM** — program do drukowania dokumentów WordStar
- **WSTEST.TXT** (3 KB) — plik testowy

# Edytor KOMPLET

## Opis

KOMPLET — polski edytor tekstu dla systemu CP/M. Posiada zaawansowane funkcje: makra, definiowalne klawiatury, obsługę cyrylicy. Polski odpowiednik WordStara.

## Pliki

- **KOMPLET.COM** (10 KB) — główny program
- **E.OV1** (31 KB) — główna nakładka edytora
- **O.COM** (1 KB) — nakładka pomocnicza
- **MAKRO.LIB** (10 KB) — biblioteka makr
- **CYRYLICA.COM** (3 KB) — obsługa znaków cyrylicy

### Definicje klawiatur
- **D100.EDT** — definicja dla drukarki D-100
- **K.EDT** — definicja klawiatury K
- **NX-15.EDT** — definicja dla drukarki NX-15
- **SH.EDT** — definicja klawiatury SH

### Inne
- **FORMAT4.COM** (2 KB) — formatowanie dyskietek
- **AUTOEXEC.SUB** (128 B) — skrypt automatycznego uruchamiania

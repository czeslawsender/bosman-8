# dBase II

## Opis

dBase II — system zarządzania relacyjnymi bazami danych dla CP/M. Jeden z najpopularniejszych programów biznesowych lat 80.

## Pliki

### Program główny
- **DBASE.COM** (19 KB) — interpreter/polecenia dBase
- **DBASEOVR.COM** (41 KB) — nakładka
- **DSORT.COM** (12 KB) — sortowanie danych
- **INSTALL.COM** (14 KB) — instalator

### Narzędzia generacji (dGEN, Luis A. Castro, 1984)
- **DGEN.CMD** / **DGEN.OVL** — generator aplikacji
- **FILEGEN.CMD** — generator struktury plików
- **FORMGEN.CMD** — generator formularzy
- **LABELGEN.CMD** — generator etykiet
- **MENUGEN.CMD** — generator menu
- **FORMGEN.COM** — skompilowany generator formularzy

### Aplikacje użytkownika

Zobacz [user-programs/](../user-programs/) — aplikacje dBase: KONTAKTY (baza kontaktów), BARCLONA (Barcelona '92), MEDALE (tabela medalowa).

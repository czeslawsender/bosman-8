# Multiplan

## Opis

Multiplan — arkusz kalkulacyjny firmy Microsoft dla systemu CP/M. Polska wersja (tłumaczone menu, komunikaty i pomoc). Prekursor Microsoft Excel.

## Pliki

- **PLAN.COM** (25 KB) — główny program
- **MPFORM.OVL** (11 KB) — nakładka formularzy
- **MPLOGIC.OVL** (12 KB) — nakładka logiki obliczeniowej
- **MPPRINT.OVL** (12 KB) — nakładka drukowania
- **MPSHOW.OVL** (12 KB) — nakładka wyświetlania
- **MPSTAT.OVL** (7 KB) — nakładka statusu
- **MPSET.OVL** (1 KB) — nakładka ustawień
- **MPHELP.FIL** (29 KB) — plik pomocy
- **MPMENU.FIL** (2.4 KB) — menu
- **MPERROR.FIL** (3 KB) — komunikaty błędów
- **MPSETUP.FIL** — plik konfiguracyjny
- **MPSERIAL.NUM** (128 B) — numer seryjny
- **INVENT.TBL** — tabela inwentaryzacyjna
- **PROGNOZA.TBL** — tabela prognoz
- **RATY** — dane o ratach
- **TABLE.DIR** — katalog tabel

# LOGO

## Opis

LOGO — edukacyjny język programowania z grafiką żółwia. Używany przez użytkownika do tworzenia programów edukacyjnych z matematyki, fizyki i geometrii.

## Pliki

- **LOGO.COM** (42 KB) — interpreter języka LOGO

## Programy LOGO (.LOG)

Kolekcja zawiera łącznie **124 programy** na 8 dyskietkach. Poniżej wybrane reprezentatywne:

### Grafika i fraktale
- HILBERT1.LOG — krzywa Hilberta (fraktal)
- PEANO1.LOG — krzywa Peano
- WIRTH1.LOG — fraktal Wirtha
- LAMANA1.LOG, LAMANA2.LOG — krzywe łamane rekurencyjne
- GWIAZDK1.LOG — gwiazdka
- KOLCE1.LOG — wzór kolców

### Geometria i optyka
- OBRAZ1.LOG, OBRAZ2.LOG — optyka geometryczna (rysuje soczewki)
- KWADRAT.LOG — kwadrat
- TROJKAT1.LOG — trójkąt

### Matematyka
- SINUS.LOG — wykres funkcji sinus
- WYKRES.LOG — wykres wielomianu 3-go stopnia
- STOPER.LOG, STOPER1.LOG — animowany stoper

### Wzory dekoracyjne
- DYWANS1.LOG — dywan
- SERWETA1.LOG — serweta
- POSADZK1.LOG — posadzka
- PLATEKK1-3.LOG — sploty

### Fizyka (disc-049-b)
- DRGA1-4.LOG — drgania
- SPAD1-4.LOG — spadanie ciał
- RZUT1-2.LOG — rzuty
- TOR1-3.LOG — tory ruchu
- SILAP1-2.LOG — siły

## Obrazy LOGO (.OBR)
- PRZEKROJ.OBR, ROZETA.OBR, TARCZA.OBR (po 16 KB każdy)

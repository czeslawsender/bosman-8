# BASIC

## Opis

Interpretery języka BASIC dla systemu CP/M firmy Microsoft (MBASIC) oraz inne warianty.

## Pliki

- **MBASIC.COM** (24 KB) — Microsoft BASIC-80 — główny interpreter
- **SBASIC.COM** (26 KB) — S-BASIC
- **XBASIC.COM** (19 KB) — X-BASIC

## Programy użytkownika w BASIC

- **BRIDGE.BAS** (38 KB, 1987) — pełna gra w brydża z AI (licytacja, rozgrywka, punktacja)
- **PAWEL.BAS**, **PAWELA.BAS** — gra zręcznościowa (spadochroniarz)
- **PAWELRYS.BAS** — program rysunkowy

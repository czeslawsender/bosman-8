# Algol-M

## Opis

Algol-M — kompilator podzbioru języka ALGOL dla systemu CP/M. Umożliwia kompilację programów w języku ALGOL-M do kodu pośredniego wykonywanego przez interpreter RUNALG.

## Pliki

- **ALGOLM.COM** (13.5 KB) — kompilator Algol-M
- **RUNALG.COM** (14 KB) — interpreter/run-time dla programów Algol-M

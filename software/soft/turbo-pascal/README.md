# Turbo Pascal

## Opis

Turbo Pascal — środowisko programistyczne firmy Borland dla systemu CP/M.
Kompilator języka Pascal z wbudowanym edytorem i zintegrowanym środowiskiem (IDE).

## Pliki

- **TURBO.COM** (31 KB) — główny program (kompilator + edytor + IDE)
- **TURBO.MSG** (1.4 KB) — komunikaty programu
- **TURBO.OVR** (1 KB) — nakładka

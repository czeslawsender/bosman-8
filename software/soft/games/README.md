# Gry

## Opis

Kolekcja gier dla systemu CP/M — od prostych gier logicznych po zaawansowane szachy i brydża.

## Lista gier

### Logiczne i strategiczne
- **SZACHY.COM** (35 KB) — szachy z interfejsem znakowym
- **BLOCK.COM** (42 KB) + BLOCK.CHR — gra w klocki (typu Tetris)
- **SOKOBAN.COM** (15 KB) — układanka Sokoban (magazynier)
- **MASTER.COM** (19 KB) + MASTER.CHR — Mastermind (łamanie kodu)
- **HANOI.COM** (15 KB) — Wieże Hanoi
- **KRZYZE.COM** (10 KB) — kółko i krzyżyk
- **BRIDGE.BAS** (38 KB) — brydż (zob. user-programs/)

### Zręcznościowe
- **CATCHUM.COM** (29 KB) + CATCHUM.DAT — gra zręcznościowa
- **LADDER.COM** (9 KB) — gra w drabinę
- **PACZKI.COM** (14 KB) — gra typu Pacman

### Muzyczne i edukacyjne
- **PIANINO1.COM** (9 KB) — pianino (odtwarzanie nut przez głośnik)
- **LIFE2.COM** (20 KB) — Gra w życie Conwaya
- **CMACIERZ.COM** (10 KB), **MACIERZ.COM** (9 KB) — gry/ćwiczenia z macierzami
- **LOSOWANI.COM** (9 KB) — losowanie liczb
- **TOTO.COM** (11 KB) + TOTO.TAB — totolotek

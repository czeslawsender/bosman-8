# Narzędzia asemblerowe

## Opis

Zestaw profesjonalnych narzędzi asemblerowych i developerskich dla CP/M, głównie firmy Microsoft.

## Pliki

### Asemblery i kompilatory
- **M80.COM** (20 KB) — Microsoft MACRO-80 — asembler makro dla Z80
- **F80.COM** (27 KB) — Microsoft FORTRAN-80 — kompilator Fortran
- **MAC.COM** (12 KB) — MAC — alternatywny asembler
- **ASS48.COM** (6 KB) / **SYM48.COM** (5 KB) — asembler dla procesora 8048

### Linker i bibliotekarz
- **L80.COM** (11 KB) — Microsoft LINK-80 — linker/konsolidator
- **LIB80.COM** (5 KB) — Microsoft LIB-80 — bibliotekarz

### Narzędzia pomocnicze
- **CREF80.COM** (4 KB) — generator referencji krzyżowych
- **HEXCOM.COM** (1 KB) — konwerter plików HEX na COM
- **RAZ80.COM** (6 KB) — Z80 Reassembler v3.0 — deasembler
- **REZILOG.COM** (8 KB) + **REZILOG.HLP** (5 KB) — analizator/symulator logiczny
